# عروض السعودية الذكية

موقع عربي RTL خفيف ومجاني يعمل على GitHub Pages. يستخدم حالياً كتالوج COD Partner لمنتجات ظهرت متاحة للسعودية، مع طلب مبدئي عبر واتساب. السعر الأساسي المعروض من المنصة ليس سعراً نهائياً للعميل، ولا يصبح الطلب مؤكداً قبل مراجعة التوفر والشحن والتكاليف.

## تشغيل محلي على Windows 10

1. ثبّت Python 3 من python.org، وفَعّل خيار Add Python to PATH.
2. افتح PowerShell داخل مجلد المشروع.
3. شغّل: `py -m http.server 8000`
4. افتح `http://localhost:8000`.
5. للفحوص: `py scripts/validate_products.py` ثم `py scripts/audit_seo.py` ثم `py scripts/check_links.py` ثم `py -m unittest discover -s tests`.

## تحديث المنتجات

عدّل `data/products.json` فقط. راجع كل منتج داخل حساب COD Partner أولاً، واحفظ اسم المنتج وصورته وسعر المنصة الأساسي والدول المتاحة وتاريخ التحقق. لا تعرض سعر المنصة الأساسي كسعر نهائي، ولا تغيّر `published` إلى `true` قبل تأكيد طريقة تنفيذ الطلب والسعر والشحن. رقم واتساب موجود في الحقل `whatsapp_number` بصيغة دولية من دون علامة `+`.

## النشر المجاني

1. ارفع التعديلات إلى فرع `main`.
2. من Settings > Pages اختر GitHub Actions كمصدر النشر.
3. شغّل workflow باسم Deploy to GitHub Pages أو ادفع تعديلاً.
4. ستشغّل GitHub Actions التحقق من JSON وتدقيق SEO وفحص الروابط والنشر وتقرير الصيانة.

لا توجد أسرار أو مفاتيح API مطلوبة لتشغيل الموقع. الموقع ثابت، ولذلك يتم إرسال الطلب المبدئي عبر واتساب ثم إدخاله ومتابعته في COD Partner من لوحة الحساب.

## ملاحظات تجارية

COD Partner يخدم دولاً خليجية محددة، ومنها السعودية. وجود الحساب من اليمن لا يعني أن الشحن متاح إلى اليمن. استخدم السعودية فقط للمنتجات التي ظهرت متاحة لها في الكتالوج، وتأكد من رسوم الشحن والتكاليف قبل إعطاء العميل سعراً نهائياً. لا توجد ضمانات للزيارات أو المبيعات أو الأرباح.
