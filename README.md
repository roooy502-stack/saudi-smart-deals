# عروض السعودية الذكية

موقع أفلييت عربي RTL خفيف ومجاني، جاهز لـ GitHub Pages. الإصدار المرفق **قالب توضيحي**: لا يحتوي على منتجات أو أسعار أو روابط إحالة حقيقية.

## تشغيل محلي على Windows 10

1. ثبّت Python 3 من python.org، وفَعّل خيار Add Python to PATH.
2. افتح PowerShell داخل مجلد المشروع.
3. شغّل: `py -m http.server 8000`
4. افتح `http://localhost:8000`.
5. للفحوص: `py scripts/validate_products.py` ثم `py scripts/audit_seo.py` ثم `py scripts/check_links.py` ثم `py -m unittest discover -s tests`.

## تعديل المنتجات

عدّل `data/products.json` فقط. ابدأ بالنسخ التوضيحية، ثم استبدلها ببيانات من مصدر يسمح لك باستخدامها. لا تضف رابطاً تابعاً قبل الموافقة في البرنامج. حدّث `last_checked` مع كل سعر أو توفر.

## النشر المجاني

1. أنشئ مستودعاً عاماً باسم `saudi-smart-deals` على GitHub.
2. ارفع الملفات إلى فرع `main`.
3. من Settings > Pages اختر **GitHub Actions** كمصدر النشر.
4. شغّل workflow باسم Deploy to GitHub Pages أو ادفع تعديلاً.
5. تم ضبط روابط `index.html` و`robots.txt` و`sitemap.xml` على رابط GitHub Pages الحقيقي.

GitHub Actions ستشغّل التحقق عند كل push، وتدقيق SEO والروابط، وتنشر الموقع، وتنفذ تقرير صيانة أسبوعياً. لا توجد أسرار أو مفاتيح API مطلوبة.

## كيف تبدأ الكسب بشكل نظامي

اختر تجاراً يقبلون الناشرين في السعودية، اقرأ شروط البرنامج، قدّم طلباً باسمك الحقيقي، واستخدم الروابط والمواد المسموحة فقط. افصل بين المحتوى التحريري والإعلان، اذكر الإفصاح بجوار الرابط، ولا تعد المستخدم بسعر أو خصم إلا إذا كان موثقاً ومحدثاً. العمولة غير مضمونة، والزيارات والدخل يحتاجان إلى اختبار وصبر وامتثال للأنظمة.
